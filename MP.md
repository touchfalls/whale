### 1. ТЕХНИЧЕСКИЙ СТЕК И АРХИТЕКТУРА

- **Технологии:** Чистый HTML5, современный CSS3 (Custom Properties / переменные, Flexbox/Grid, Glassmorphism, CSS-анимации), Vanilla JavaScript (ES6+ Modules или модульный чистый JS).
- **Паттерн:** Single Page Application (SPA) с переключением экранов без перезагрузки страницы (через CSS-классы видимости / data-атрибуты или Hash-роутинг `#links`, `#server`, `#proj`).
- **Конфигурация:** Вынеси все переменные пользователя (ссылки, IP майнкрафт-сервера, username Modrinth, цвета) в отдельный объект `config.js` или секцию в начале скрипта, чтобы сайт можно было настраивать без правки логики.

Файловая структура:
├── index.html       # Единая разметка со всеми секциями/view
├── style.css        # Глобальные стили, переменные, темная тема, анимации
├── app.js          # Логика SPA, API-запросы (Modrinth, MC Status), обработчики
└── README.md        # Краткая инструкция по настройке под себя

### 2. ДИЗАЙН-СИСТЕМА И ОБЩИЙ UI

- **Фон:** Спокойный природный пейзаж с наложенным темным оверлеем (`backdrop-filter: blur()`, `rgba(0, 0, 0, 0.7)` или затемненный `background-image`).
- **Стиль:** Минимализм, эстетика терминала/clean web, моноширинные или аккуратные sans-serif шрифты (например, Inter или JetBrains Mono).
- **Адаптивность:** Полная поддержка мобильных устройств и десктопа.
- **Плавность:** Мягкие CSS-переходы (fade-in / slide) при переключении между экранами и кнопка возврата на главную `[ ← back ]` во внутренних разделах.

### 3. СПЕЦИФИКАЦИЯ ЭКРАНОВ

#### Экран 1: Главная (Home View)
- Минималистичный центральный блок (один аккуратный контейнер/карточка).
- Три акцентные кнопки навигации: `[links]`, `[server]`, `[proj]`.
- При клике плавно открывается соответствующий экран.

#### Экран 2: `[links]` (Socials & Contacts)
- Минималистичный список/сетка из аккуратных прямоугольных плашек.
- Каждая плашка содержит: иконку сервиса (SVG или Unicode/Font), название и саму ссылку.
- **Интерактив:** При наведении на плашку (hover) текст названия и бордер плавно перекрашиваются в фирменный цвет сервиса (Brand Color).
- Список ссылок:
  1. Telegram (🔐 `tg`)
  2. Letterboxd (фирменный зеленый/оранжевый `#00E054`)
  3. Serializd (фирменный синий/аквамарин `#3A86FF` или `#00D2FF`)
  4. Direct Messages / Email
  5. Blog
  6. Boosty (фирменный оранжевый `#F15F2C`)
- Все внешние ссылки открываются в новом окне (`target="_blank"` и `rel="noopener noreferrer"`).

#### Экран 3: `[server]` (Minecraft Status)
- Строгий, «сырой» текстовый минимализм без эмодзи.
- Отображение статуса сервера в формате: `status: [online]` (зеленый цвет) или `status: [offline]` (красный цвет).
- **Интеграция:** Использовать бесплатный публичный API для проверки статуса (например, `https://api.mcstatus.io/v2/status/java/{server_ip}` или `https://api.mcsrvstat.us/3/{server_ip}`) через `fetch()`. Добавь индикатор загрузки `[checking...]`.
- Ниже статуса — блок с текстом для подачи заявки на вайтлист с кликабельной ссылкой на Telegram.

#### Экран 4: `[proj]` (Modrinth Projects)
- Страница с автоматической подгрузкой проектов пользователя с Modrinth API.
- **Интеграция:** Асинхронный GET-запрос к `https://api.modrinth.com/v2/user/{username}/projects`.
- Карточки проектов: название, краткое описание, иконка проекта (если есть) и счетчик общего количества скачиваний (downloads).
- Клик по карточке открывает страницу мода на Modrinth (`https://modrinth.com/project/{slug}`) в новой вкладке.
- Предусмотри обработку состояний: скелетон/загрузка `[loading projects...]` и обработка ошибок (если API недоступен).
